使用说明:
  1. 启动程序: python main.py
  2. 在 GUI 中输入上表中的 m, n, k, j, s 五个值
  3. 点击 Execute 执行
  4. 结果中的 'Number of groups' 应尽量接近 LJCR最优值
  5. 如果 status=绝对正确, LJCR值就是理论最优, 求解器达到该值即为完美
  6. 如果 status=可能最优, LJCR值是目前已知最佳, 求解器结果不差于该值即可
